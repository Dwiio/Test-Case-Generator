# Test Case Generator — Redesigned UI

A refreshed responsive interface for the supplied Test Case Generator prototype.

## Run
Open `index.html` in a modern browser. No build step or package installation is required.

## Files
- `index.html` — page structure and form
- `style.css` — responsive visual design
- `script.js` — validation, rule-based generation, rendering, clipboard, and CSV export

## Design
Clean cream-and-blue QA workspace, responsive sidebar/header, clearer form hierarchy, category selection cards, generated results panel, and mobile layouts.

## Implementation note
The generator remains rule/template-based. It is not connected to an LLM or remote AI API. Review generated cases before using them.
